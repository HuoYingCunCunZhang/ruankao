📌 软考中级的「英文题」核心不是考阅读，而是考英文缩写 / 术语 ↔ 中文概念的对应。下面先讲 3 类题型怎么破，再给高频缩写速查、易混对比和例题。

① 3 类英文题 + 应对策略

1
缩写 ↔ 含义题（最常见）
给出 IaaS / SaaS / RACI，问中文含义，或反过来。
👉 抓全称：IaaS=Infrastructure as a Service=基础设施即服务；SaaS=Software as a Service=软件即服务；PaaS=Platform as a Service=平台即服务。先记「首字母 + 关键词」。
2
英文描述 → 概念识别题
给一句英文定义，问是哪个概念（如 "a formal document that authorizes the project" → Project Charter）。
👉 抓锚点词：baseline（基准）、audit（审计）、change request（变更请求）、stakeholder（干系人）、deliverable（可交付成果）。不逐字翻译，找专业术语。
3
易混缩写对比题
如 IaaS/PaaS/SaaS、RFI/RFQ/RFP、SPI/CPI、EV/PV/AC。
👉 记区别点：SPI 看进度、CPI 看成本；RFI 问信息、RFQ 问报价、RFP 问建议。
4
通用技巧
① 先看选项再读题干；② 排除中文对应明显错的；③ 不纠结生词，抓住认识的术语锚点；④ 缩写题若全称记不清，用「首字母 + 场景」推。

③ 易混缩写对比（必看）

IaaS / PaaS / SaaS：基础设施即服务（租硬件）/ 平台即服务（租平台）/ 软件即服务（租软件）。
RFI / RFQ / RFP：信息邀请书（问信息）/ 报价邀请书（问报价）/ 建议邀请书（问建议，最正式）。
EV / PV / AC：挣值（实际完成×预算）/ 计划值 / 实际成本。
SV / CV：进度偏差=EV-PV / 成本偏差=EV-AC。
SPI / CPI：进度绩效指数=EV/PV / 成本绩效指数=EV/AC。
EAC / ETC / BAC：完工估算 / 完工尚需估算 / 完工预算。
WBS / OBS / RBS：工作分解结构 / 组织分解结构 / 资源分解结构。
RAM / RACI：职责分配矩阵 / 责任分配矩阵（R执行、A负责、C咨询、I知情）。
CCB / CMO：变更控制委员会（决策机构）/ 配置管理员（作业机构）。
ROI / NPV / IRR：投资回报率 / 净现值 / 内部收益率。
RPO / RTO：恢复点目标（允许丢失的数据量）/ 恢复时间目标（恢复所需时间）。
CIA：保密性 Confidentiality / 完整性 Integrity / 可用性 Availability。

⑤ 考前 30 秒口诀

缩写题 → 先抓全称、再看选项；
句子题 → 找锚点词（baseline / audit / request / stakeholder）；
易混题 → 问信息 RFI、问报价 RFQ、问建议 RFP；SPI 管进度、CPI 管成本；
实在不会 → 排除法 + 场景联想，别空着。
