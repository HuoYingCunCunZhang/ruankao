# 系统集成项目管理工程师 · 备考助手

软考中级「系统集成项目管理工程师」（第 3 版教材，2024 下半年启用）的离线备考小应用。

**本版内容已依据《系统集成项目管理工程师教程（第 3 版）》逐章重新梳理**，站在「作者思路 = 出题思路」的视角组织：每一章先讲**作者的写作思路**（= 命题逻辑），再画**逻辑架构图**，然后逐节展开**核心内容 + 重点 + 考点 + 口诀**，最后配两类训练题。

## 训练题（两部分，清晰区分）

| 类型 | 说明 |
| --- | --- |
| 📗 **教材原题** | 教材每章末尾「本章练习」的**选择题**（题干、选项、答案忠于原文）+ **思考题**（题干原文，附参考要点） |
| ✍️ **自编题** | 出题人结合本章高频考点新拟的选择题，每题带解析 |

进入任一章，可分别点「📗 教材原题」和「✍️ 出题人自编题」按钮作答；错题自动进「错题本」。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用外壳（界面 + 交互，单文件可直接打开） |
| `content.js` | 全部学习内容数据（章节/考点/口诀/训练题），由 `_build/chNN.js` 组装生成 |
| `manifest.webmanifest` + `sw.js` + `icon-*.png` | PWA 安装与离线缓存（部署到 HTTPS 后生效） |

> `_build/` 目录存放各章内容源片段（`chNN.js`）与组装脚本（`assemble.py`），`content.js` 为其组装产物；修改内容后运行 `python _build/assemble.py` 即可重新生成。

## 怎么装到手机上（3 选 1）

### 方式 A：直接打开（最简单，立即可用）
1. 把整个文件夹通过 **微信「文件传输助手」** 或网盘发到手机；
2. 手机上找到 `index.html`，用浏览器（Safari / Chrome / 夸克 / 微信内置浏览器）打开；
3. 打开后即可离线查看（内容全部内嵌）。学习进度保存在浏览器本地。

### 方式 B：添加到主屏幕（像 App 一样，推荐）
- **iPhone（Safari）**：打开 `index.html` → 底部「分享」→「添加到主屏幕」→ 命名后完成。
- **Android（Chrome）**：打开后点右上角菜单 →「添加到主屏幕 / 安装应用」。

### 方式 C：部署成真正的 PWA（可「安装」，断网也能用）
把整个文件夹上传到任意免费静态托管（Gitee Pages、GitHub Pages、Cloudflare Pages、Vercel 等），获得一个 `https://` 链接后：
- 手机浏览器打开该链接 → 菜单会直接出现 **「安装应用」** 按钮；
- 安装后像原生 App 一样，桌面有图标、全屏运行、完全离线可用。

> 提示：方式 A/B 在 `file://` 下 Service Worker 不生效（属浏览器安全限制），但内容本来就全部内嵌，不影响使用；方式 C 才能获得完整「安装 + 离线预缓存」体验。
